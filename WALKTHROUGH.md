# Mystery House - walkthrough

One line = one command, finish it with RETURN. The automatic test
(`tests/walkthrough.txt`) plays the same sequence. At `-more-` any key
continues; a letter typed there already starts the next command.

## Into the house, kitchen
```
u
open door
go door
get note
read note
look room
w
open cabinet
look cabinet
get matches
open refrigerator
look refrigerator
get pitcher
look sink
get butterknife
water on
get water
```

## Library, dining room: fire and small key
```
e
e
get note
w
s
get candle
light candle
look
pour water
look hole
get key
```
After `light candle` you trip over the rug with the next command and start a
fire - that is intended. Only `pour water` with a full pitcher saves you.
